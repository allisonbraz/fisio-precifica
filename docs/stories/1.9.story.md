# Story 1.9 — Confiabilidade Financeira e Ativação do FisioPrecifica

**Epic:** Correção do Modelo de Precificação
**Status:** Ready for Review
**Prioridade:** CRÍTICA
**Agente:** @dev

---

## Contexto

A revisão pré-piloto identificou riscos de tributação genérica, dupla contagem de impostos,
custos variáveis que não acompanham o volume, circularidade em reservas percentuais e
inconsistências entre margem e markup. Também foram observadas fricções de ativação:
progresso iniciado artificialmente, onboarding interrompido e ausência de uma faixa clara
entre preço operacional, sustentável e estratégico.

## Critérios de Aceite

### AC-1: Tributação orientativa e editável
- [x] Não apresentar MEI como opção válida para fisioterapia
- [x] Simples Nacional explicar fator R e não presumir 6% silenciosamente
- [x] Alíquota efetiva sempre editável pelo usuário
- [x] Aviso explícito para validação com contador
- [x] Impostos sobre faturamento não aparecem novamente como custo variável padrão

### AC-2: Custos variáveis escaláveis
- [x] Custos variáveis aceitam valor mensal, valor por sessão ou percentual da receita
- [x] Simulações de ocupação recalculam custos por sessão/receita
- [x] Dados antigos continuam carregando como valores mensais

### AC-3: Reservas e preço sem circularidade
- [x] Reservas fixas entram no numerador da fórmula
- [x] Reservas percentuais entram no denominador
- [x] Fórmula protege contra percentuais totais inviáveis
- [x] Testes cobrem resultados analíticos conhecidos

### AC-4: Terminologia consistente
- [x] Margem é sempre calculada sobre receita
- [x] Markup não é apresentado como margem
- [x] Diferenciar margem operacional e margem disponível
- [x] Alertas usam a mesma definição das telas

### AC-5: Três referências de preço
- [x] Exibir piso operacional, preço sustentável e preço estratégico
- [x] Explicar o que cada referência inclui
- [x] Preservar o preço definido pelo usuário como cenário comparável

### AC-6: Ativação corrigida
- [x] Progresso não começa em 50% apenas por valores padrão
- [x] Onboarding continua na etapa correta após navegar
- [x] Promessa pública distingue diagnóstico gratuito de recursos completos

### AC-7: Qualidade
- [x] Testes existentes passam
- [x] Novos testes cobrem impostos, reservas e custos variáveis
- [x] Typecheck passa
- [x] Build passa
- [x] Fluxo principal é verificado em viewport mobile
- [x] Lint é executado localmente e no CI
- [x] CI valida o build de produção

### AC-8: Sincronização segura entre dispositivo e conta
- [x] Nenhum autosave ocorre antes de o carregamento remoto inicial terminar
- [x] Uma conta sem dados remotos pode salvar seus dados iniciais após a leitura
- [x] A troca de conta refaz a leitura remota e não reutiliza o cache da conta anterior
